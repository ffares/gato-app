# gato

Builds of [gato](https://fares.net/gato/), a native macOS terminal.

No source here — this repository holds the signed, notarised disk images and
nothing else.

## Install

```sh
brew install --cask ffares/tap/gato
```

Or take the disk image from [Releases](../../releases) and drag gato to
Applications. Every build is signed with a Developer ID and notarised by
Apple, so it opens with a double click.
